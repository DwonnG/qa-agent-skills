# Root Cause Analysis

Review the bug ticket and identify the underlying cause, not just surface symptoms. Analyze technical or process failures that led to the issue.

## Structure

### Jira Ticket Overview
- Ticket key, title, and description summary

### Root Cause
- What went wrong at a technical or process level
- The failing component, configuration, or logic
- Trace the origin (missed validation, logic flaw, deployment misstep)

### Contributing Factors
- Surrounding conditions that enabled the issue (missing test coverage, lack of alerts, recent changes)

### Preventive Actions
- Specific steps to avoid recurrence (test improvements, automation, alerting, process fixes)

Focus only on information from the ticket. Avoid speculation beyond what is provided.
