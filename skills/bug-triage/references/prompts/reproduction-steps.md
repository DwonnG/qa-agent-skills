# Reproduction Steps

Write clear reproduction steps from the ticket description and comments.

## Structure

### Environment
- Where the issue occurs (staging, production, browser/device)
- Relevant configuration or prerequisites

### Steps to Reproduce
- Sequential user or system actions
- Input values, navigation paths, API calls

### Expected vs Actual
- **Expected**: what should happen
- **Actual**: what actually happens

Only include information found in the ticket. Do not assume beyond what is provided.
